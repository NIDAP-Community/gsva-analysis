## Included functionality

- Sample-level GSVA, ssGSEA, z-score, or PLAGE enrichment from normalized
  continuous gene-expression data.
- Required separate tables for expression, sample metadata, and pathway
  membership.
- `gene_column=auto` selects `Gene`, then `GeneName`; auto collection selection
  uses Human or Mouse Hallmark memberships as appropriate.
- Structured result bundle with enrichment scores, heatmap, run metadata,
  manifest, and session information.
